# Hardware roadmap

The current release is simulation-only.

## Planned hardware stages

### Stage 1: synchronized capture

- Eight matched microphones.
- One shared sampling clock.
- Multichannel ADC.
- Hardware trigger.
- Raw multichannel recording.

### Stage 2: calibration

- Channel gain calibration.
- Channel delay calibration.
- Microphone-position measurement.
- Frequency-response characterization.

### Stage 3: controlled validation

- Loudspeaker at known azimuth/elevation.
- Quiet room.
- Repeated measurements.
- Comparison with simulation.

### Stage 4: real environment

- Speech source.
- Background noise.
- Reverberant room.
- Multiple source tests.

Hardware results must be reported separately from simulation results.
