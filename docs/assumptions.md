# Assumptions and limitations

The current simulation assumes:

- One acoustic source.
- Far-field propagation.
- Known microphone coordinates.
- Known speed of sound.
- Perfect channel synchronization.
- Identical microphone responses.
- No clipping.
- No reverberation.
- Additive white Gaussian noise.
- Static array geometry.
- Static source direction during each trial.
- Correct local field-of-view prior.

The following are not yet modeled:

- Room impulse responses.
- Early reflections.
- Diffuse noise.
- Gain mismatch.
- Phase mismatch.
- Sample-clock drift.
- ADC nonlinearities.
- Mechanical vibration.
- Temperature gradients.
- Multiple sound sources.
- Near-field curvature.
- Real speech recordings.
