# Figures

This directory is reserved for plots generated from benchmark JSON files.

Recommended figures:

- Angular-error histogram.
- Angular-error CDF.
- Azimuth error versus true azimuth.
- Elevation error versus true elevation.
- SNR comparison.
- Worst-case direction plot.

Figures should include:

- Seed.
- Number of trials.
- SNR.
- Array geometry.
- Estimator version.
